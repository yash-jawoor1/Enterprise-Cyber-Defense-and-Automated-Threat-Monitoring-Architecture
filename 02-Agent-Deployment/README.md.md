# 🛠️ Step 2: Wazuh Agent Installation & Endpoint Configuration

## 1. Overview & Core Capabilities

The **Wazuh Agent** is a lightweight monitoring application installed on endpoints (Windows, Linux, macOS). Its primary responsibility is to collect security telemetry from the monitored host and forward it securely to the central Wazuh Manager for real-time analysis, correlation, and storage.

The agent provides essential security capabilities:

- **Log Collection:** Ingests operating system logs (Windows EventChannel, Sysmon, Application logs).
    
- **File Integrity Monitoring (FIM):** Detects creation, modification, and deletion of critical system and user files.
    
- **Security Configuration Assessment (SCA):** Audits host configurations against security benchmarks (CIS controls).
    
- **Malware & Anomaly Detection:** Identifies rootkits, suspicious processes, and abnormal host behaviors.
    
- **System Monitoring:** Tracks inventory, active processes, listening ports, and system resource metrics.

## 3. Step-by-Step Deployment Procedure

### Step 3.1: Dashboard-Assisted Agent Deployment Setup

1. Open a web browser on the Windows endpoint and access the **Wazuh Dashboard**:
    
    Plaintext
    
    ```
    https://<WAZUH_MANAGER_IP>
    ```
    
2. Log into the Dashboard with administrative credentials.
    
3. Navigate to **Endpoints** $\rightarrow$ Click **Deploy new agent**.
    
4. Configure the deployment parameters:
    
    - **Operating System:** `Windows`
        
    - **Architecture:** `x86_64` / `.msi` package
        
    - **Server Address:** `<WAZUH_MANAGER_IP>`
        
    - **Agent Name:** `WIN-ENDPOINT-01`
        

### Step 3.2: Download & Execute PowerShell Registration

1. Download the official **Wazuh Agent MSI Installer** (`wazuh-agent.msi`) from the official repository.
    
2. Open **Windows PowerShell as Administrator**.
    
3. Execute the registration and installation command string generated by the Wazuh Dashboard:
    

PowerShell

```
# Execute deployment command with designated Manager IP and Agent Name
Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.14.9-1.msi -OutFile ${env:tmp}\wazuh-agent.msi; msiexec.exe /i ${env:tmp}\wazuh-agent.msi /q WAZUH_MANAGER='<WAZUH_MANAGER_IP>' WAZUH_AGENT_NAME='WIN-ENDPOINT-01' WAZUH_REGISTRATION_SERVER='<WAZUH_MANAGER_IP>'
```

4. Start the agent service via PowerShell:
    
    PowerShell
    
    ```
    NET START WazuhSvc
    ```
    
5. Confirm the service state:
    
    PowerShell
    
    ```
    Get-Service -Name WazuhSvc
    ```
    
    _Expected Output:_ Status should report **`Running`**.
    

### Step 3.3: Endpoint GUI & File System Verification

1. Navigate to the default agent directory on the host:
    
    Plaintext
    
    ```
    C:\Program Files (x86)\ossec-agent
    ```
    
2. Verify critical components are present:
    
    - `ossec-agent.exe` (Main agent service)
        
    - `ossec.conf` (Local agent configuration file)
        
    - `win32ui.exe` (Wazuh Agent GUI interface)
        
    - `logs/ossec.log` (Local agent operational logs)
        
3. **Wazuh Agent GUI:** Launch `win32ui.exe` to manage services, view active configurations, or inspect local agent log entries visually.
    

## 4. Connection Verification & Manager Triage

1. Return to the **Wazuh Dashboard** UI.
    
2. Navigate to **Management** $\rightarrow$ **Agents**.
    
3. Search for the registered host by **Name** (`WIN-ENDPOINT-01`) or **ID** (`001`).
    
4. **Status Validation:** Verify the agent displays an **`Active`** connection state.
    

> **SOC Note:** An **Active** status confirms bi-directional communication over TCP ports `1514` (agent data dispatch) and `1515` (agent registration).
