
# 6. Wazuh Agent Installation and Configuration

## 6.1 What is the Wazuh Agent?

The Wazuh Agent is a lightweight application installed on endpoints such as Windows, Linux, and macOS systems. Its primary responsibility is to collect security-related data from monitored endpoints and forward it to the Wazuh Manager for processing and analysis.

The agent provides several security monitoring capabilities, including:

- **Log Collection:** Collects operating system and application logs.
    
- **File Integrity Monitoring (FIM):** Monitors changes to files and directories.
    
- **Security Configuration Assessment (SCA):** Evaluates endpoint security configurations against security policies.
    
- **Malware Detection:** Helps identify suspicious activity and indicators associated with malware.
    
- **System Monitoring:** Collects information about the endpoint and its security state.
    

## 6.2 Supported Platforms

Wazuh supports agent deployment on the following operating systems:

- Windows
    
- Linux
    
- macOS
    

For this lab, a Windows endpoint is used to demonstrate agent installation, registration, and connectivity with the Wazuh Manager.

## 6.3 Deploying a New Agent from the Wazuh Dashboard

### Step 1: Access the Wazuh Dashboard

Open a web browser on the Windows host and access the Wazuh Dashboard using the Manager's IP address.

```
https://<WAZUH_MANAGER_IP>
```

Log in to the Dashboard.

Navigate to the **Endpoints** section and click **Deploy new agent**.

### Step 2: Download the Windows Agent Installer

Select the Windows operating system and the appropriate installation package.

Download the Windows `.msi` installer from the official Wazuh documentation:

[https://documentation.wazuh.com/current/installation-guide/wazuh-agent/wazuh-agent-package-windows.html](https://documentation.wazuh.com/current/installation-guide/wazuh-agent/wazuh-agent-package-windows.html)

Save the installer on the Windows endpoint.

### Step 3: Configure Agent Settings

Configure the deployment settings in the Wazuh Dashboard.

Provide the following information:

|Configuration|Description|
|---|---|
|Operating System|Windows|
|Server Address|IP address of the Wazuh Manager|
|Agent Name|Unique name assigned to the endpoint (e.g., PC1)|
|Installation Package|Windows MSI installer|

The Server Address must point to the Wazuh Manager so the endpoint can communicate with it.

  ![[Pasted image 20261102221440.png]]

### Step 4: Install and Register the Windows Agent

After configuring the deployment options, the Wazuh Dashboard generates the commands required to register the agent.

Follow these steps:

1. Open Windows PowerShell as Administrator.
    
2. Copy the registration and installation commands generated by the Wazuh Dashboard.
    
3. Paste and execute the commands in PowerShell.
    
4. Follow the generated instructions to complete the agent registration.
    
5. Allow the installation and registration process to finish.
    

These commands establish communication between the Windows endpoint and the Wazuh Manager.

**Note:** Use the commands generated by your own Wazuh Dashboard. The exact commands may depend on the selected deployment configuration.

## 6.4 Verify Agent Connection

Once the registration is successful, return to the Wazuh Dashboard.

Follow these steps:

1. Navigate to the **Agents** section.
    
2. Look for the newly added agent in the list.
    
3. Identify the agent using its assigned name.
    
4. Ensure that its connection status is **Active**.
    

An Active status indicates that the agent is connected to the Wazuh Manager.

## 6.5 Windows Agent Management

Once installed, the Wazuh Agent provides a graphical user interface (GUI) for managing the agent.

The GUI can be used for:

- Configuring the agent.
    
- Opening the agent log file.
    
- Starting the agent service.
    
- Stopping the agent service.
    

This interface helps administrators manage and troubleshoot the Windows agent.

## 6.6 Default Agent Installation Directory

By default, the Wazuh Windows Agent files are stored in:

```
C:\Program Files (x86)\ossec-agent
```

This directory contains the agent installation files and supporting components, including configuration and log files.

Administrators can inspect this directory when troubleshooting agent configuration or connectivity issues.

## 6.7 Installation Verification Checklist

After completing the deployment, verify the following:

- Windows agent installer downloaded successfully.
    
- Wazuh Agent installed on the Windows endpoint.
    
- Wazuh Manager IP address configured correctly.
    
- Agent registration completed successfully.
    
- Agent appears in the Wazuh Dashboard.
    
- Agent connection status displays Active.
    
- Windows agent GUI is accessible.
    
- Default installation directory is accessible.
    

## 6.8 Conclusion

The Wazuh Windows Agent installation and registration process establishes communication between the Windows endpoint and the Wazuh Manager.

Once connected, the endpoint can provide security-related information to the centralized Wazuh monitoring platform.

This deployment forms the foundation for subsequent SOC lab activities, including:

- Security event monitoring.
    
- File Integrity Monitoring (FIM).
    
- Security Configuration Assessment (SCA).
    
- Suspicious activity investigation.
    
- Threat detection and incident analysis.
